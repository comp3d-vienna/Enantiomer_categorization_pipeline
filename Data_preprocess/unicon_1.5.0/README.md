# UNICON

UNICON is a simple, easy-to-use command-line tool that can be used to prepare, compare, or
generate large small molecule datasets.

If you use UNICON, please cite:
Sommer, K.; Friedrich, N. O.; Bietz, S.; Hilbig, M.; Inhester, T.; Rarey, M. UNICON: a powerful and
easy-to-use compound library converter. J Chem Inf Model 2016, 56 (6), 1105-1111.
DOI: https://doi.org/10.1021/acs.jcim.6b00069

### Activation

After obtaining a license, you will have to activate UNICON with that license. To do so,
open the license file, copy the content, and execute UNICON as follows:
```
$ ./unicon --license <paste_your_license_here>
```


## Quick Start

1. Converting molecules
```
$ ./unicon -i example_data/LOBSTER_ligands.sdf -o results/output.smi
```

2. Converting a file with multiple components into multiple entries

```
$ ./unicon -i example_data/LOBSTER_ligands.sdf -o results/output_multi.smi --multi
```

3. Extracting small molecules from PDB files
```
$ ./unicon -i example_data/1a00.pdb -o results/1a00.smi
```

4. Generating tautomeric forms
```
$ ./unicon -i example_data/LOBSTER_ligands.sdf -o results/drugbank_tautomers.smi –-tautomer ensemble
```

5. Generating a normalized tautomeric form
```
$ ./unicon -i example_data/LOBSTER_ligands.sdf -o results/default_tautomers.smi --tautomer single
```

6. Generating 3D coordinates
```
$ ./unicon -i example_data/input.smi -o results/output.sdf --generate 3 --hydrogens
```

7. Generating a set of conformers
```
$ ./unicon -i example_data/propranolol.sdf -o results/conformers.sdf --conformer 1
```


## Usage

UNICON can be started with one or more molecule input files or directories. Allowed input file
formats are: MOL(.mol), MOL2(.mol2), PDB(.pdb), mmCIF(.cif), SDF(.sdf), SMILES(.smi/.smiles),
and InChI(.inchi). UNICON can be used for various applications as exemplified in the above
'Quick Start' examples. You can, for example, convert file formats into one another, generate
tautomeric forms, protonation states, stereoisomers, conformers, or extract ligands by name.

On Linux/macOS systems, redirection from and to UNICON is possible too:
1. Extracting all ligands in a PDB file
```
$ cat 1a00.pdb | unicon --inFormat pdb -o output.smi
```
2. Using the UNICON output immediately as input for another tool
```
$ ./unicon -i example_data/input.smi --outFormat sdf 2> conversion.log | someOtherTool
```


## Output

The molecules generated by UNICON can be written to MOL2, SDF, SMILES, and InChI files. You can
also split the output molecules into several output files with a specified number of entries with
the '--split' option.


## Configuration

For an overview of all settings, you can start UNICON using the help command:
```
$ ./unicon --help
```


## Error Reporting

If you want to report a problem via software.zbh@uni-hamburg.de, please provide as much information
as possible. An error report should contain a short description of the problem, detailed
reproduction steps, and input data to reproduce the issue.
